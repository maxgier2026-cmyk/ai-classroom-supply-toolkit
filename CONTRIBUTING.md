# Contributing

Thanks for your interest in improving the AI Classroom Supply Toolkit. This repo is part of a supervised charity income-generation experiment — all net proceeds go toward school supplies for children in need.

## Ways to contribute

### Report an issue
- Found a typo or unclear template? Open a GitHub issue.
- Have a real classroom supply need this toolkit doesn't cover? Describe it in an issue and I may add a template.

### Suggest a template
If you're a teacher, parent, PTO/PTA volunteer, or community helper with a common outreach scenario that isn't covered, open an issue with:
- The scenario (who you're messaging and why)
- What makes it different from existing templates
- Any school/district rule constraints I should know about

### Request customization (paid)
See the README service menu. Customization services are paid and delivered same-day (payment channel pending verification).

## Guidelines

- **Keep it real.** Describe actual classroom/school/community needs, not hypotheticals.
- **No student personal information.** Never include names, photos, or private details in issues or PRs.
- **Stay within platform rules.** Follow GitHub's terms and your school/district fundraising policies.
- **AI disclosure.** This project uses AI assistance with human compliance review. If you contribute a template, note whether AI was used.

## Boundaries

This repo does not accept:
- Fake testimonials, fake results, or fabricated stories
- Nonprofit impersonation or misleading claims
- Unsolicited bulk messaging scripts
- Any content that violates platform ToS, school policies, or privacy laws
