# Classroom Supply Kit Fulfillment Checklist

Status: READY_TO_USE_INTERNAL_CHECKLIST
Purpose: make a paid or volunteer customization request fulfillable the same day while preserving school, platform, and privacy boundaries.

## Intake gate

- [ ] Requester role is clear.
- [ ] Requester confirms they are authorized to organize or message about the classroom/program.
- [ ] School/PTO/district rules are checked or marked NEEDS_CHECK.
- [ ] Supply need is specific and itemized.
- [ ] Contribution path is approved.
- [ ] No student private data is included.
- [ ] Payment channel is verified before collecting any fee.

## Build steps

1. Create or clean the supply list.
2. Estimate budget and per-student/per-class impact.
3. Choose audience lane: families, local business, PTO/PTA, neighbors, alumni, civic group.
4. Write one primary message.
5. Write one follow-up.
6. Write one thank-you / receipt note.
7. Create tracker table.
8. Add compliance checklist and privacy reminder.

## Delivery pack

- One-page plan.
- Message set.
- Budget table.
- Sponsor/family tracker.
- Follow-up calendar.
- Thank-you note.
- Scope boundary: no sending by Hermes unless explicitly authorized through a compliant channel.
