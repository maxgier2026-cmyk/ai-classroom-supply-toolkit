# Sponsor Outreach Kit Builder

Status: READY_TO_USE_TEMPLATE
Purpose: turn one classroom supply need into a clear, local-sponsor-ready kit without spam, pressure, fake urgency, or student private data.

## 1. Inputs to collect first

| Input | Required? | Notes |
|---|---:|---|
| Authorized organizer name/role | Yes | Teacher, PTO/PTA volunteer, parent coordinator, school staff, etc. |
| School/program name | Yes | Use only if you are authorized to represent it. |
| District/school fundraising rule checked | Yes | If unknown, pause and ask the school office/PTO. |
| Supply list with quantities | Yes | Keep the request concrete. |
| Estimated total budget | Yes | Use the budget calculator or your own itemized list. |
| Wishlist/payment link | Optional | Only use an authorized school/PTO/teacher wishlist or approved collection path. |
| Sponsor recognition allowed? | Yes | Some schools restrict logos, public thank-yous, or social posts. |
| Privacy constraints | Yes | Do not include student names, photos, addresses, or personal stories without written permission. |

## 2. One-page kit structure

Copy and fill this block before sending any sponsor request.

```text
Classroom / Program:
Organizer and role:
Authorization checked with:
Supply goal:
Estimated budget:
Deadline, if real:
Approved way to contribute:
What sponsors receive, if allowed:
Privacy rule:
Follow-up date:
```

## 3. Local sponsor message

Subject: School supply support request for [classroom/program]

Hi [Name],

I'm helping organize an authorized supply support effort for [classroom/program]. The current need is specific: [short supply list or category], with an estimated budget of [amount].

If your business is able to help, the approved contribution path is here: [wishlist/payment/drop-off details]. If recognition is allowed under school/PTO rules, we can provide [thank-you option]. If not, we will simply confirm receipt and use.

No pressure either way — I wanted to ask clearly and keep the request transparent.

Thank you,
[Name]
[Role]

## 4. No-pressure follow-up

Hi [Name], just following up once on the school supply request for [classroom/program]. The need is still [short need], and the approved contribution path is [link/details]. If now is not a fit, no problem — thank you for considering it.

## 5. Thank-you / receipt note

Hi [Name], thank you for supporting [classroom/program]. We received [items/amount] on [date]. The supplies will be used for [general use only — no student private data]. We appreciate the help.

## 7. Compliance check before sending

- [ ] I am authorized to contact this sponsor for this school/classroom/program.
- [ ] The contribution path is approved.
- [ ] The message is truthful and specific.
- [ ] No student private data is included.
- [ ] No fake urgency, guilt pressure, or guaranteed sponsor benefit is claimed.
- [ ] Any public recognition offer follows school/PTO rules.

## 8. Same-day customization offer input

If requesting a custom kit, provide:

1. Role and authorization status.
2. Supply list and estimated budget.
3. Target audience: local business, PTO/PTA, parents, neighbors, alumni, or civic group.
4. Approved contribution path.
5. Recognition limits.
6. Deadline, only if real.

Expected custom output: 1 sponsor one-sheet, 2 message versions, 1 follow-up, 1 thank-you, 1 tracker table, and 1 compliance checklist.
