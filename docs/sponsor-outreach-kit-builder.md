# Sponsor Outreach Kit Builder

Use this alongside the main toolkit to prepare a clear, privacy-safe local sponsor request.

Canonical file: https://github.com/maxgier2026-cmyk/ai-classroom-supply-toolkit/blob/main/toolkit/sponsor-outreach-kit-builder.md

Quick route:

1. Confirm you are authorized to organize the request.
2. Itemize the supply need and estimate the budget.
3. Confirm the approved contribution path.
4. Send only truthful, specific, no-pressure messages.
5. Track replies and send thank-you notes without student private data.
